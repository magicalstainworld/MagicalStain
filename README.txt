Magical Stain - Henna Artist website (HTML + CSS + JS)

Open index.html in a browser. No build step needed.

Structure
  index.html     page markup
  css/style.css  styles and design tokens (:root)
  js/main.js     all content data (top of file) + behaviour
  images/        put your logo and photos here

Add your logo:   in js/main.js set SITE.logo = "images/logo.png"
Add photos:      in js/main.js give GALLERY items img:"images/name.jpg"
Edit details:    SITE, BRANCHES, SERVICES, PACKAGES, REVIEWS at top of js/main.js
